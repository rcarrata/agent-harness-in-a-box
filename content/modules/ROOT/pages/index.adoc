= {openshell} Agent Harness on {ocp-short} Guide

Structured demos for running {openshell} and AI coding agents on {ocp-short}.

* Sandboxed agent runtimes with four-layer security (network, binary binding, filesystem, process)
* OIDC authentication via {rhbk} with per-user sandbox isolation
* AI agents (OpenCode, Claude Code, Hermes) running inside {openshell} sandboxes
* Interactive CTF to explore and test each security boundary
* Automated install scripts with TLS and MLflow tracing options

Requires {ocp-short} 4.19+ with cluster-admin access.

IMPORTANT: This guide is not a replacement for the link:https://docs.nvidia.com/openshell/latest/[official {openshell} documentation^]. It is a companion resource with opinionated scripts and configurations to accelerate deployment on {ocp-short}.

== What is {openshell}?

{openshell} is NVIDIA's agent-first platform providing safe, sandboxed runtimes for autonomous AI agents. It enforces security boundaries through four isolation layers:

* *Network default-deny* - An HTTP CONNECT proxy controls all outbound traffic. Only endpoints declared in the policy are reachable.
* *Binary binding* - Only specific executables (e.g. `python3`, `node`) can reach allowed endpoints. `curl` is blocked even for permitted hosts.
* *Landlock filesystem* - Kernel-level filesystem access control. Paths must be explicitly declared as read-only or read-write.
* *Process isolation* - The agent runs as the unprivileged `sandbox` user, never as root.

The {openshell} gateway runs as a StatefulSet on {ocp-short} and manages sandbox pods through the link:https://github.com/kubernetes-sigs/agent-sandbox[Agent Sandbox^] CRD (`sandboxes.agents.x-k8s.io`).

== Getting Started

Clone the repository and work from its root directory. All commands and file paths in this guide are relative to the cloned repo.

[source,bash,subs="+attributes"]
----
git clone {repo-url}.git
cd agent-harness-in-a-box
----

You also need:

* {ocp-short} 4.19+ cluster with `oc` CLI authenticated as cluster-admin
* Helm 3.x
* `openshell` CLI (link:https://docs.nvidia.com/openshell/latest/install[install guide^])
